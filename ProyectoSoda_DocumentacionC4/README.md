# Descripción del Proyecto

El Sistema de Pedidos para Soda busca digitalizar la gestión de órdenes de alimentos y bebidas, permitiendo a clientes y colaboradores interactuar mediante una plataforma web que agiliza el proceso de atención, reduce errores y mejora el control operativo.
