# ADR-003 Control de Acceso Basado en Roles

## Estado

Aceptado

## Fecha

24/10/2026

## Contexto

Existen distintos tipos de usuarios:

- Cliente
- Cocina
- Cajero
- Administrador

Cada uno requiere permisos diferentes.

## Decisión

Implementar autorización mediante roles.

## Consecuencias Positivas

- Mayor seguridad.
- Control granular de accesos.
- Mejor administración.

## Consecuencias Negativas

- Mayor complejidad de configuración.
