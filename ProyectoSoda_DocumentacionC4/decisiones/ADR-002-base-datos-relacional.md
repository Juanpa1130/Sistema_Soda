# ADR-002 Uso de Base de Datos Relacional

## Estado

Aceptado

## Fecha

24/10/2026

## Contexto

El sistema administrará:

- Usuarios
- Pedidos
- Productos
- Pagos

La información está altamente relacionada.

## Decisión

Utilizar una base de datos relacional.

## Consecuencias Positivas

- Integridad referencial.
- Facilidad de consultas.
- Consistencia de datos.

## Consecuencias Negativas

- Estructura más rígida que NoSQL.
